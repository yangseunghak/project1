Design System

COADS 디자인 시스템

개인프로젝트2(Next.js) 기준으로 정리한 레이아웃, 컬러, 타이포그래피, Header/Footer 컴포넌트 가이드입니다. 토큰은 app/globals.css와 tailwind.config.ts를 기준으로 합니다.

그리드

모든 페이지는 .container-wide 컨테이너 안에서 정렬되며, 섹션별로 CSS Grid를 조합합니다.

컬러 가이드

:root CSS 변수와 Tailwind theme.extend.colors에 정의된 브랜드 컬러입니다.

--navy #071A2B Footer 배경, 섹션 제목, 다크 UI
--cobalt #185ADB Eyebrow, nav 언더라인, 강조 포인트
--ink #101214 기본 본문 텍스트
--muted #34383D 보조 텍스트, 설명 문구
--line #E8EBEE 구분선, 카드·헤더 테두리
--paper #F6F7F8 페이지 배경
--white #FFFFFF 카드, 헤더 스크롤 배경
btn-primary #061844 Primary CTA 버튼 배경
btn-secondary #1148BE Secondary 버튼 테두리
progress #2F6BFF 스크롤 프로그레스 바
